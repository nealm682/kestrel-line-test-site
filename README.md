# kestrel-line-test-site

**FICTIONAL test website.** Kestrel Line Plumbing & Mechanical is not a real
company. Every name, contract, number, rating and certification is made up.

It exists to test GovCon Tracker's knowledge-base start (spec 049): reading
a company website, picking the useful pages, stripping personal contact
details, ignoring instructions hidden in page text, and treating marketing
language as a claim rather than evidence.
